             Summary of Submission Rules for Ufomind List
     From: campbell@ufomind.com (Glenn Campbell, Las Vegas)
     Date: Tue, 2 Sep 1997 12:33:25 -0800


  Before submitting any message to the Ufomind list, please note...
  -- This is not a "true" mailing list. It is only a mechanism to add
  documents to my server. People can subscribe if they want, but this is
  not the main purpose. (There are only about 20 subscribers.)
  -- Every document submitted must have an "Index:" entry at the bottom,
  linking it to an existing Ufomind page.
  -- Documents will not be accepted that already exist at stable addresses
  on the web. (This includes UFO UpDates messages.)
  If a document already exists on the web, it should be linked directly
  to the appropriate Ufomind page, not sent to the list.
  -- Copyrighted documents, such as newspaper articles, are not usually
  not accepted.
  Glenn
