                            SUMMARY ANALYSIS

                    REMOTE VIEWING (RV) SESSION C 4



1.  (S) This report provides documentation of a remote
viewing session conducted for training purposes to enhance
a remote viewer's demonstrated ability.

2.   (S)  This was a most interesting session. The remote
viewer appeared to be asleep during the first twenty minutes
of this session. After twenty minutes, the interviewer read
the coordinates aloud, but very softly to the viewer again.
At this time the viewer seemed to awaken, picked up the sealed
target envelope and immediately began to describe the target
location. The target selected for this session was the Gateway
Arch, located on the Mississippi River in St. Louis, Missouri.
The remote viewer's impressions during this session correlate
very well with the target location (see TAB B). The viewer's
strongest and most recurring impression was that of a horse
shoe shape and he described it as being an opening in the target,
an entrance or the mouth of the target. The arch is also known
as "the Gateway to the West". The viewer also had a strong
sensation of cold, black water. What better way to describe
the "muddy Mississippi."

3.  (S)  The protocol used for this session is detailed in
the document, Grill Flame Protocol, AMSAA Applied Remote
Viewing Protocol (S) , undated.

4.   (S) Following is a transcript of the viewer's impressions
during the remote viewing session. At TAB A are drawings made
by the viewer reference his impressions of the target site.
At TAB B is a map and description of the target site.

5.  (S)  This session was conducted simultaneously with
Session C5 which had the same target.
