           This phenomina can be demonstrated remotely, and I wouldn't even have to
           demonstrate it for you exactly. I could send you some C++ source code
           that shows how this works.
           Given a large number of truly randomly generated numbers, or
           psuedorandom numbers, my model can predict what future random numbers
           will be with greater than the expected probability from chance alone, by
           looking at previously generated random numbers. This is a known fallacy
           in the world of statistics because truly 'random' things do not care
           about any external factor except for their inate probability.
           If you wanted to test me we would have to agree on the expiriment so I
           could tailor write source code to do it exactly as we agreed. Here is
           what I prepose.
           The random source of numbers we use can be downloaded from
           http://random.org/files they are 1 meg files of random bits (0s & 1s),
           created in a way that is considered to be 'truly' random.


   Unfortunatly, you also have access to them, so that won't fly. We'd
   have to request a private random sequence, to which you do not have
   access. This sequence can be encrypted and sent to you (password to
   be delivered after the experiment is over) so that you can verify we
   aren't cheating.


           Then the program will run a 100 trial expiriment, each trial consisting
           of it looking over 1000 random bits in sequence. After looking over a
           number of them it may decide to guess at future random bits. Each time
           it guesses it will count either as one success or one failure out of the
           total number of guesses it makes for each trial. If it doesn't decide
           to make a guess for one trial then the program will preform another
           trial on top of the 100.


   Roughly how often will it guess (you said "may decide")? Does it need to
   know if its guesses were right or wrong during the experiment or can this
   information be kept secret?
   I'm puzzled by the "number of guesses it makes for each trial". That would
   be one, right (or none, I suppose)? Obviously if you make two guesses you
   can be sure to be right, but that's not very interesting.


           At the end of each trial it will calculate the probability of its
           success by the number of guesses it made corect divided by its total
           number of guesses. At the end of 100 trials all of the inidividual
           trials probabilitys will be added together and divided by the number of
           trials to come up with the true final probability. This true final
           probability will always be greater than the expected probability for the
           expiriment, and the program can be run as many times as you like to
           verify it.


   How much greater? You'd expect to get 50% right by chance, but 51% is
   well within the bounds of experimental error and wouldn't impress me
   (depending on the number of trials). I'm not an expert on this, but
   unless we can run enough trials to see, oh, 2 standard deviations away
   from expectation, then I don't think this will work.
