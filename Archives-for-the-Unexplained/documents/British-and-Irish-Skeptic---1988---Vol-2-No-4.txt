       Sheldrake's theory is almost beautiful in the way

isation has been set up to fund tests, and ( unsuc­
cessful) ones have already been carried out ( see The
Skeptical Inquirer, Spring 1988, p 298) .

       However, ( if one is to keep an open mind) it is
not necessarily the theory itself which is pseudosci­
entific. Generously assuming the theory to be viable
but unprovable, can one apply Occam's razor and ask
if there is any evidence that such a theory is needed?
