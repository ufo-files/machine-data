                             SUMMARY ANALYSIS

                   REMOTE VIEWING (RV) SESSION C 14



1.   (S) This report provides documentation of a remote viewing
session conducted for training purposes to enhance a remote
viewer's demonstrated ability.

2.   (S) Target correlation in this session cannot be determined
due to insufficient target data.  The remote viewer was very
relaxed during this session and his attention was completely
focused on the task at hand.  Because the viewer was in such deep
mental state, ambient room noise, which was minimal, did not
disturb him.

3.  (S)  The protocol used for this session is~tailed in the
document, Grill Flame Protocol, AMSAA Applied Remote Viewing
Protocol (S), undated.

4.   (S) Following is a transcript of the viewer's impressions
during the remote viewing session. At TAB A are drawings made
by the viewer reference his impressions of the target site. At
TAB B is available target data.
