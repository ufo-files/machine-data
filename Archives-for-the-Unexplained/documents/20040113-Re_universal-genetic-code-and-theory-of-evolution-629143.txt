   dford3@gl.umbc.edu [david ford] wrote...


           What is wrong with the following 3 sets of claims, if anything?:
           Set #1
           The DNA code is universal.
           The theory of evolution, which invokes descent from a common ancestor,
           predicts that the DNA code that is present in all known organisms will
           be the same in all known organisms.


   No, but it might predict that the codes will be basically the
   same throughout the groups of organisms that do happen to
   share a common ancestor. The theory nowhere predicts that
   there must be a single origin of life; it just so happens
   that that is indeed what the evidence indicates.


           And that is what we find when we compare the prediction with
           observation: the DNA code specifying what arrangement of DNA gets
           translated as what protein is the same among all organisms/ is
           universal.


   With minor variations. The point is, there's no reason at all
   for a common code if organisms were created separately. Humans
   for example could have been created with an entirely different
   code from apes and all other animals. Wolves, if a separately
   created "kind" from foxes might happen to use a different
   non-DNA molecular system entirely. Result: a clear "biotic
   message" that things were separately created that no one would
   ever be able to explain by evolution.


           Score a point for the theory of evolution, which successfully
           predicted this observation.


   Not really a prediction or requirement, but it's still a
   confirmation.


           Set #2
           The DNA code isn't universal.
           The theory of evolution, which invokes descent from a few common
           ancestors, predicts that the DNA code that is present in all known
           organisms will not be the same in all known organisms.


   It predicts no such thing, but one might predict that if
   there were a few or many separate "kinds" of life there may
   be a similar number of different DNA codes [assuming that
   they all would even use DNA].


           And that is what we find when we compare the prediction with
           observation: the DNA code specifying what arrangement of DNA gets
           translated as what protein isn't the same among all organisms/ isn't
           universal.


   It's universal, with minor variants.


           Score a point for the theory of evolution, which successfully
           predicted this observation.
