                  I want to run CLI without a cache manager or any other add on. Is this possible and does this
                  mean only one work unit will be cahed in cli folder?


          The CLI from SETI Classic will run without any add-ons. It doesn't cache
          any units; it downloads one, processes it, and uploads the result, then
          downloads another unit and starts processing.

          Caching would imply having an additional WU to start working on when the
          in-process unit is completed and the result upload is being attempted.
