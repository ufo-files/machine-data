NOTES:

The data was taken off a system called the ERIT (Enroute Radar Intelligence tool) which is Pentium class computer used for recording and analyzing radar data only.   The data is acquired from radar modem splitter ports which originate from the same sources used for the FAA’s host computer system.   Lately, the ERIT computer has had trouble getting a connection to an Internet Zulu time server, so the internal PC clock will be free running and unsynchronized.   The PC time is usually off by several minutes at the most.  This does not invalidate the data since all incoming radar message are “time stamped” by one clock source.

All incoming radar messages are referenced by True North, except BAD which is an ASR9 direct link and the returns are referenced Magnetic North of 4.4 degrees E.

QAZ, QSK,LBB, BAD are terminal ASR9s have scan rates of 4.8 seconds.
