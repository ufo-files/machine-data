Vertical oblong object descended towards earth and then hovered; then ascended back to sky; 2nd object looked like black cloud irregular shaped

Around 8 pm we saw a bright round ball in the sky which started descending toward earth and became a vertical object with lights. Sometimes we saw the lights and then it looked like the lights disappeared as this object continued towards earth. There was a vapor trail behind the object about twice the length of the object and continued moving with the object, 

After about 3-4 minutes of descent, the object eventually stopped its descent and hovered as a bright ball. This lasted for about an hr. We took our eyes off this object as we talked and when we looked back at the object, the object seemed to have moved horizonally to the left about 6-8 inches from where it first settled. It stayed in this location for awhile. 

Then we saw a small black cloud right in front of us to the left of the object but closer to us. We didn't think much of it but it was outstanding because all the other clouds in the sky were brilliant white. This one was black and it changed forms quickly like it was turning. Then it disappeared in about 5 minutes as quickly as it came.

Immediately after the black cloud disappeared the vertical object began to ascend into heaven. Looked like thrusters were turned on as a vaper trail connected to the object. This vaper trail was about twice the length of the object. Then the object disappeared into space. It took about 2 minutes for the object to disappear.
