I let my dog out about 6:10am still very dark. Stars were visible. The big dipper is directly overhead. I noticed a "star" moving across the sky a little bit to the south from NW to SE really fast. I assumed it was a satellite. But then it occurred to me that there were 4 in a perfectly straight line, exactly the same distance apart and going exactly the same speed. I tried to see if "it" covered any other stars - if it was one object - but it didn't. The I noticed another grouping of 3 lights/stars behaving in exactly the same way going exactly the same direction but behind and parallel to the first "string." Do satellites travel really fast in a perfectly straight line exactly the same distance apart and at the same speed? The lights were the same same size as other visible stars but obviously I couldn't see the altitude. I only had my phone and it couldn't see the objects.
