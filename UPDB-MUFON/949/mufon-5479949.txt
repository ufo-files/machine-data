I found this flying object on my vacation photos. I didn't see it while taking the picture and was very surprised to find it. I was taking the picture with great caution, I wanted to align these monuments you can see in the picture.

I was on vacation in Paris in October 2013 with my family. I like taking pictures. So when we stood at a spot where the Eiffel Tower is aligned with the Obelisque, I made a photo. I didn't see anything strange then. But when I was back home some days later, I noticed a black flying object on this photo, only on this photo, I made about 200 photos on this vacation. I am no professional photographer, but I tried to enlarge it and used some filters with Picasa. So I found that on the left side of the object there is a cloud (that is hiding a part of the object ) and inside the cloud there seems to be a small spot. The object is all black but if you enlarge the photo it seems there are some lights around it. My first thought was that it could be an UFO, but it seemed really strange and then I forgot about it. But recently I watched a show about MUFON and I decided to send you this picture, because it doesn't seem to be an airplane or something known. I don't know if it could be a drone, but it seems very big. I don't know what it could be, but I can assure you that this is a genuine photo taken by me. This has never happened to me before and I am taking photos all the time. Thank you very much.
