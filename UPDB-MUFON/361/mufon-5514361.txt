(GS) Firey like object descending from the sky appearing to be very close.

I was in my front yard looking for an arrow on the ground that I lost while practicing shooting my bow. I happened to look up and noticed what looked like an object on fire. My initial impression was that it was a firework. I dismissed this because the object lasted for several seconds without any sound or visual effect, and there was no smoke trail. The object was very wide and not very tall, so it was not spherical shaped. It moved in a straight path and looked to be falling. I lost sight of the object when it passed behind my house. It appeared that the object was close to the ground because I waited to hear it crash, but I never heard any sounds or felt any vibrations. This occured on Saturday November 10,2012 between 5:30 and 6:00. I know this because the six oclock news came on right after I got off the phone with my wife. The object was so close and so pronounced that I expected to hear something on the news, but nothing was ever reported. I wonder if I am the only witness to this sighting. Also, I must note that I have indicated that the light was yellow-orange, but I am color blind so that is not reliable. The object was very bright, of that I am certain.
