silver, triangular object seen ascending toward cloud. Disapeared BEFORE entering cloud

With my husband, walking the dog along the cliff-top path in Shanklin. We both spotted the object at the same time, silver, triangular in shape and reflective. It was ascending at a slight angle towards some clouds, at which point it disappeared just before reaching the cloud, as if it had just become invisible (cloaked?). We waited for it to appear again as the cloud above it was very patchy, but it did not. We kept looking up and around in the hope of sighting it again, but only saw an occasional aircraft. It was only when we saw the aircraft that we realised the object must have been huge, because although the aircraft we saw was much closer to us, it was probably about one quarter of the size.
