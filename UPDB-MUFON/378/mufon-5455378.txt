{cak} Reddish orange round/orb

1955 hrs sunday feb 16th saw object in nw sky. It attracted my attention because it was close to landing pattern of commercial aircraft but I couldn't understand why reddish orange light. At first I thought it was a drone because it flew on a straight path and then hovered for a couple of seconds. When the object moved again the lights dimmed. I could tell that it was gaining altitude fast. It ended up being like a pin prick like a satellite but I was able to see it until it was out of range and faded out. As if that weren't enough when I turned back to where it came from there was another. Same color same path and then another behind it same color same path. All of these objects were separated by 10 to 20 seconds. The 3rd trailing object was moving faster like it was trying to catch up with the second object. The second object appeared to stop and hover wher the first one did, the lights dimmed and went in sw direction. I couldn't tell if it gained altitude like the first but I watched it fade away as it headed towards down town phoenix. The third object did the same thing. It got to where the the first two stopped and hovered, it hovered, dimmed and went west. It was apparent that it gained some altitude but not like the first object. I watched it fade away. I have seen things before and could rationally explain that maybe it was something else but a ufo. This I can't explain at all.
I'm a Navy vet. 2 years active duty as a radarman and am quite familiar with aircraft identification. I jave have never seen anything like this.
