Object which resembled cluster of silvery metallic pipes jumbled together floating in space out over ocean. Appearance was unusual.

Observed unusual looking object hovering over ocean some distance southeast of location where I was sitting on beach. Couldn’t identify what the object could be due to it’s strange appearance, looked like a jumble of stainless steel pipes jumbled together, so reached for my binoculars in my backpack only to see object “wink” out of sight. Checked around me but could tell noone else nearby had observed the object disappearing. Watched the same sector of the sky for over 20 more minutes but object never reappeared. Only reporting this sighting because I’ve never read of one where the object looked like this one and the fact that it disappeared in a instance still blows my mind. And I’m curious if you’ve had any similar reports.
