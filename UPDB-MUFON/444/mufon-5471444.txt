{rjl} 2 glowing objects with an expanding light tail almost like a comet in the atmosphere

2 glowing objects with an expanding light tail almost like a comet in the atmosphere. The length of the tail could have been a few miles.

When it started it look like two airplane con trails glowing to the north. then two object appeared, one behind the other. The con trail began to expand from the front object to 10,000 times the diameter of the lighted object as if it were venting something.

Behind the lead object was another object following almost like a flare doing spirals behind the front object. the second object seemed to peter out and fall along the western side as the main object continued.
