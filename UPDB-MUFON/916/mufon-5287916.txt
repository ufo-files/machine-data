Cigar shaped object seen in sky behind my house

My wife and I saw an object that, at first glance, looked like an airplane as it was long and parallel to the ground. It had windows like an airplane. But it had no wings. I was confused because I could clearly see a long row of windows which I would not be able to see unless the airplane had been very close. The object made no sound. I was confused because if the object was close enough that I could clearly see the windows and if it were an airplane, it would be moving so fast, I would not be able to see it for more than a second or two. I estimate that I clearly saw this object for about 30 seconds moving from north to south. There was at least one bright light shining from one or more of the windows. Weird!
