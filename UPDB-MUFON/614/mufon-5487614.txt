{dr}Red/Orange glowing orb with no noise traveling faster than jet but slower than meteor

I was helping my neighbor install a garage heater when I went to get some tools from my garage when I observed a red/Orange glowing orb traveling from North to Northeast for about 8 seconds with no noise. I thought it might be the red wing lights on airplane but noticed entire object was glowing. I've seen meteors and space garbage reentry before and this was a lot slower but way faster than a jet or airplane. The object was just above cloud level so it disappeared when it went behind a cloud bank. The path was straight and consistent but the speed was what didn't make any sense to me. I stood there for a minuet or two waiting to see if there was a trailing light of some sort but didn't see any.
