{jpg} Hovering object in what appears to be upper atmosphere

I stepped outside at around 5pm EST on December 6th, 2019. I saw a very bright object in the sky, and at first assumed it to be a planet. The object appeared to be about as bright as Jupiter on a clear night, except when I was viewing the object it was still very much daylight. I remained outside to observe the object and noticed that it was reflecting sunlight. As the sun set the object grew dimmer and dimmer until it was no longer visible at around 6pm. During that time the object did not move as far as I could tell, nor did it change altitude. I did get the impression that the object may have been triangular in shape, but that also could have been an illusion from focusing on a dot in the sky for so long. I later checked to see if there were any satellites in orbit that should have been visible and stationary for that amount of time but found nothing that matched. I also frequently looked at a star chart during my observation to see if there were any normal celestial events that I should be able to observe at the time and also came up with nothing.
