{cak} Green object w. trail ejected two red

On November 10th at 3am, several witnesses observed a greenish object traveling in a straight horizontal line from East to West about 5 degrees over the horizon--the object ejected two reddish "flares" before disappearing. 

Timeline:
0s: Greenish object appears, several people notice it. Object appears as bright as a space shuttle re-entering the atmosphere, and leaves a trail about as long. Object travels in-line with the horizon.

+2s: Object ejects 1 flare-like red object, which falls a distance of about 1.5 inches (when measured at arms length)

+3s: Object ejects second flarelike object which matches the first

+5s: Both "flares" have disappeared.

+6s: Original green object disappears, having travelled about 6 inches (when measured at arms length).

No alcohol, drugs, etc were being consumed.
